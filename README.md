# Keepsake — landing page

Адаптивний односторінковий лендінг дизайн-агенції Keepsake (лабораторна робота №7, завдання 4).

**Демо:** https://airnova567.github.io/landing-keepsake/

## Технології

- Семантичний HTML5: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, `form`; один `h1`, коректна ієрархія заголовків.
- Чистий CSS без фреймворків та UI-бібліотек; reset у `css/reset.css`, стилі у `css/style.css`.
- Шрифти з Google Fonts (`font-display: swap`): Oswald 300/400/700, Open Sans 300/400/700, Dancing Script 700, Lora (логотипи клієнтів і лапки відгуку).
- Іконки — інлайн-SVG.

## Рішення

- **Mobile first.** Базові стилі для 375px, далі `@media (min-width: 768px)` та `@media (min-width: 1280px)`. Сторінка коректна від 320 до 1920px, без горизонтального скролу (виняток — рядок чипсів на мобайлі).
- **Дизайн-токени** (кольори, шрифти, відступи, висота header) — CSS-змінні в `:root`; значення звірені з макетом Figma. Загальна висота сторінки збігається з макетом: 3772 / 4482 / 5228 px.
- **Контейнер:** бокові поля 20 / 40 / 90px, максимальна ширина контенту 1100px, на ширших екранах центрується.
- **Розкладка:** Flexbox для header, hero, футера, відгуку, постів; CSS Grid для сітки робіт (1 / 2 / 3 колонки) та блоків послуг, статистики й логотипів. Абсолютне позиціонування лише для оверлеїв карточок, мобільного меню та fixed-елементів.
- **Мобільне меню без JS:** прихований, але фокусований `checkbox` + `:checked ~ …`; бургер перетворюється на хрестик.
- **Фільтр портфоліо без JS:** радіокнопки + `:checked ~ …` та атрибут `data-category`. «Load more works» — `checkbox` (показує всі 9 карточок).
- **Ховер карточки:** оверлей зі знаком «+», назвою, лінією та категорією; той самий стан вмикається через `:focus-visible` / `:focus-within`.
- **Форма підписки:** HTML-валідація email, обов'язковий прапорець згоди; стани default / focus / error (`:user-invalid`, помилка зв'язана через `aria-describedby`) / success (`:target`, повідомлення замість полів). Реальної відправки немає.
- **Fixed header** зменшується до 64px і отримує тінь при скролі (CSS scroll-driven animation, у браузерах без підтримки залишається фіксованим). Кнопка «вгору» 44×44 завжди на екрані.
- **Доступність:** видимий `:focus-visible`, `aria-label` на іконкових посиланнях, `aria-current` в навігації, декоративні елементи приховані від скрінрідерів, `prefers-reduced-motion`.
- **Продуктивність:** ілюстрації карток та прев'ю створені засобами CSS (растрових зображень немає), шрифти з `font-display: swap`.

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
python3 -m http.server 8000
```
