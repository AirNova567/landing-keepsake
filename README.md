# Keepsake — landing page

(лабораторна робота №7, завдання 4).

**Демо:** https://airnova567.github.io/landing-keepsake/

## Технології

- Семантичний HTML5: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, `form`; один `h1`, коректна ієрархія заголовків.
- Чистий CSS; reset у `css/reset.css`, стилі у `css/style.css`.
## Рішення

- **Mobile first.** Базові стилі для 375px, далі `@media (min-width: 768px)` та `@media (min-width: 1280px)`. Сторінка коректна від 320 до 1920px, без горизонтального скролу.
- **Контейнер:** бокові поля 20 / 40 / 90px, максимальна ширина контенту 1100px, на ширших екранах центрується.
- **Розкладка:** Flexbox для header, hero, футера, відгуку, постів; CSS Grid для сітки робіт (1 / 2 / 3 колонки) та блоків послуг, статистики й логотипів. 
- **Мобільне меню:** прихований, але фокусований `checkbox` + `:checked ~ …`;
- **Фільтр портфоліо:** радіокнопки + `:checked ~ …` та атрибут `data-category`. «Load more works» — `checkbox`
- **Ховер карточки:** оверлей зі знаком «+», назвою, лінією та категорією; той самий стан вмикається через `:focus-visible` / `:focus-within`.
- **Форма підписки:** Валідація email, обов'язковий прапорець згоди; стани default / focus / error.
- **Fixed header** зменшується до 64px і отримує тінь при скролі. Кнопка «вгору» 44×44 завжди на екрані.
- **Доступність:** видимий `:focus-visible`, `aria-label` на іконкових посиланнях, `aria-current` в навігації, декоративні елементи приховані від скрінрідерів, `prefers-reduced-motion`.
